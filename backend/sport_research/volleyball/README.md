# Volleyball Research Workspace

This folder is for building SFTC's volleyball sport knowledge base.

The order is:

1. Build the research map and agent briefs.
2. Research each domain into structured draft JSON files.
3. Validate the drafts.
4. Convert drafts into app-facing sport teaching progressions, skill assessments, tactical rules, role profiles, and S&C planning rules.
5. Wire volleyball retrieval into workout generation the same way cricket is wired.

Do not create production database records directly from unsummarized articles or long source text. Source material should become structured coaching knowledge first.
