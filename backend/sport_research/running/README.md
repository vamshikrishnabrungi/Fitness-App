# Running Endurance Research Pack

This folder contains the app-facing running endurance knowledge export generated by
`backend/ingest_running_teaching_database.py`.

## Scope

The first running pack covers:

- beginner run-walk and easy-running progression
- aerobic base and long-run development
- tempo, threshold, fartlek, intervals, strides, and hills
- 5K/10K, half-marathon, marathon, and trail/hill contexts
- running strength and conditioning support
- return-to-run symptom gates
- heat, terrain, and environment adjustments
- level progression from beginner to intermediate to advanced

## Collections Produced

- `sport_profiles`
- `sport_training_rules`
- `planning_rules`
- `sport_teaching_progressions`
- `sport_skill_assessments`
- `sport_level_transition_rules`
- `running_workouts`
- `running_plan_rules`
- `source_sections`
- `source_registry`
- `knowledge_sources`

## Notes

The running pack is meant to guide the AI on what to prescribe and when. Exercise
definitions, strength exercise coaching cues, and mobility details should still come
from the exercise, strength, mobility, and plyometric libraries.

The next useful expansion would be a deeper race-specific pack for 5K, 10K,
half-marathon, marathon, and trail running with more detailed pace-zone and taper
rules.
