# Data classification manifest

| Dataset | Purpose | PostgreSQL target state |
|---|---|---|
| Curated exercises | Canonical methods, effects, eligibility and relations | Import after catalogue validation |
| Four-week exercise templates | Reference progressions by quality and athlete level | Import as versioned recipes/templates |
| Scenario overlays | Phase, schedule and constraint adjustments | Import as bounded template/rule data |
| Sport priority matrix | Sport × role/event × phase × goal retrieval priorities | Import as sport-demand priority data |
| Workout-template import CSV | Admin authoring format | Import only after an operator supplies and validates rows |

Research papers, prose reports, source registries, audit results, old generated
workouts and draft teaching databases are deliberately excluded from this
manifest.
